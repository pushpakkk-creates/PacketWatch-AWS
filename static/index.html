Lab talking points

Explain the deployment in concrete AWS terms

Why EC2?

A configurable Linux virtual machine hosts the Python API and trained model.

Why Security Groups?

They act as stateful virtual firewalls controlling traffic to the instance.

Why systemd?

It runs the API as a Linux service and can restart it after failure or reboot.

Why CloudWatch?

When configured, it can collect logs and metrics and trigger alarms when thresholds are breached.
